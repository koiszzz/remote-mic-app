# 小米遥控器鼠标移动模式测试手册

## 适用范围

- 分支：`feat/xiaomi-mouse-mode`（基线 `origin/main` `d48f77951ebd46a54ea46066ef29cb0efbb71fef`）
- 平台：macOS；目标硬件为小米蓝牙遥控器（RC001 / RC003）
- 目标：验证长按小米遥控器电源键进入/退出鼠标移动模式、模式内方向键移动光标、确认键单击左键、确认键长按右键、其余按键与回归功能不变，以及断连/停用后的安全恢复。
- 验证边界说明：单元测试与本地构建仅验证状态机、坐标夹紧和事件路由；真实遥控器手感、权限弹窗、多显示器与第三方 App 点击结果须按本手册实机完成验收。

## 测试前准备

1. 安装并启动本次构建的测试包（`~/Applications/SayAll.app`）。
2. 在“系统设置 → 隐私与安全性”确认无线麦 SayAll 已获得 **输入监控** 与 **辅助功能** 权限（若本机为无开发者证书的本地 `ad-hoc` 签名测试包，覆盖安装后如系统重新要求授权，需在系统设置中重新勾选授权并重启 App）。
3. 打开“按键映射”页面，开启“启用自定义按键功能”，并确认小米遥控器已连接。
4. 准备一个文本编辑窗口（如 TextEdit）、Finder 窗口或浏览器窗口用于验证左键点击、双击与右键上下文菜单。

## 用例 1：进入与退出鼠标移动模式

1. 保持在普通模式，**短按**一次小米遥控器电源键后立即松开（< 0.55 秒）。
2. **长按**小米遥控器电源键约 0.55 秒以上，观察顶部提示与菜单栏图标，随后松开。
3. 再次**长按**小米遥控器电源键约 0.55 秒以上，随后松开。

预期结果：

- 第 1 步：只执行电源键原有的单击动作（默认 `Esc`），**不会**进入鼠标移动模式。
- 第 2 步：达到长按阈值后屏幕顶部出现“鼠标移动模式已开启”轻提示，菜单栏图标切换为鼠标样式，且松开电源键时不会补发 `Esc`。
- 第 3 步：达到长按阈值后屏幕顶部出现“已退出鼠标移动模式”轻提示，菜单栏图标恢复正常连接样式；退出后方向键与确认键恢复原有绑定。

失败判定：短按电源键误进入鼠标模式、长按不进入或松开补发 `Esc`、菜单栏图标不变化，或再次长按无法退出。

## 用例 2：方向键移动光标与屏幕边界

1. 长按电源键进入鼠标移动模式。
2. 分别短按一次上、下、左、右键；再按住某一方向键约 1.5 秒。
3. 同时按住两个垂直方向键（例如“右 + 下”）。
4. 将光标移动到屏幕四边及多显示器（如有）交界处继续移动。

预期结果：

- 短按即有小幅精准位移（约 4 px 起步）；持续按住时平滑加速（约 180 px/s 起步，1.2 秒内渐进加速至 1400 px/s），松键立即停止、不漂移。
- 同时按住两个垂直方向键时沿 45° 斜向移动，速度不翻倍。
- 单屏边缘停在屏幕内；多屏拼接处可平滑跨屏，不会跳入异形拼接的空白死角。
- 模式内按方向键不会触发原方向键绑定，也不会使前台文档光标移动。

失败判定：短按无响应、加速突兀、松手后继续滑动、越出屏幕外或前台文本光标同时移动。

## 用例 3：确认键左键单击、连续双击与长按右键

1. 在鼠标移动模式下把光标移到一个文件夹或文本选区/按钮上。
2. 短按一次确认键（< 0.55 秒后松开）。
3. 在 Finder 文件夹图标或文本单词上快速连续短按两次确认键。
4. 在桌面空白处或文本编辑区，**长按**确认键（≥ 0.55 秒）直至弹出菜单后再松开。

预期结果：

- 第 2 步：松开确认键瞬间立即产生一次鼠标左键点击，无明显额外延迟。
- 第 3 步：连续两次快速短按递增 `clickState`，能原生触发 macOS 双击打开/选词。
- 第 4 步：按住达到 0.55 秒时立即弹出右键上下文菜单，松开确认键时不会再补发左键点击。

失败判定：短按确认键仍发送 Enter、长按右键后松开补发左键关闭了右键菜单，或点击落点偏离当前光标位置。

## 用例 4：非受管键与稳定回归

1. 在鼠标移动模式下，短按电源键、按音量加/减、主页键、语音键。
2. 在鼠标移动模式下关闭遥控器蓝牙或退出无线麦 SayAll，再重新连接/启动。

预期结果：

- 电源键短按仍执行原有单击动作（默认 `Esc`，可用来关闭刚打开的右键菜单）；音量、主页、语音键保持原有功能不受影响。
- 断连、停用自定义映射、系统休眠或重启 App 后自动退出鼠标移动模式，菜单栏图标恢复，不残留卡死按键或持续移动。

## 日志采集与排查

- 日志路径：`~/Library/Logs/RemoteMic/`（`.rmlog` 或 `runtime.log`）。
- 重点关注事件前缀：`MOUSE MODE phase=activated|deactivated|rejected`、`MOUSE MODE click button=left|right`、`HID BUTTON button=power trigger=longPress action=toggleMouseMode`。
